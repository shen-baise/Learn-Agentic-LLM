# 智能体 LLM 的行为研究

> **本章学习目标**
>

> - 解释"LLM 行为"的含义，并描述如何对其进行研究。

## 15.1 什么是 LLM 行为？

2019 年，一支来自计算科学、行为科学和认知科学领域的跨学科团队描述了一个新兴研究领域的出现：机器行为学（Machine Behaviour）。该领域"关注对智能机器的科学研究，不是将其视为工程产物，而是将其视为一类具有特定行为模式和生态特征的主体"[Rahwan et al., 2019]。机器行为学天然是跨学科的，因为它在*技术*的内在层面（算法、数据结构、训练过程）与实际使用的*环境与情境*层面之间整合知识。

机器行为学中的研究方法可与动物行为学或心理学中的工作相比较：在那些领域中，要理解动物和人类的运作方式，同样需要整合内在层面（如生物物理学、神经学）和生态层面（与环境的交互、社会交互）的洞见。

研究机器行为——尤其是 LLM 行为——的一个重要实践动机在本部分的导言中已经提及：随着 LLM 日益融入我们的日常工作和个人环境，了解和理解其行为倾向与模式已变得十分紧迫。同样也存在科学层面的动机：由于大规模神经架构的复杂性（它们表现为*黑箱*），很难通过分析手段追溯其运作机制。（尽管机械可解释性（mechanistic interpretability）领域确实在尝试这样做，参见第 21 章。）以实证方式研究这类复杂系统的*行为*是我们理解它们的另一条互补路径。换言之，由于交互的复杂性，即使一位理论工程师对 LLM 的架构和训练数据了如指掌，他可能仍然无法预测 LLM 在各类情境下的响应。行为研究方法旨在填补这一空白。

什么算作*行为*取决于被研究系统的功能可供性（affordance）¹和研究范围。例如，对于一个基础 LLM，行为等于模型基于 token 的推理所产生的*输出*。另一方面，对于一个能够执行网络搜索和运行代码等操作的智能体 LLM，行为还可以包括其为获得特定输出或实现特定效果而执行的*动作*。正如我们将看到的，一些研究只考虑最终输出并将其视为模型的行为；另一些研究则对中间步骤同样感兴趣。

## 15.2 实验探测 LLM 行为

近年来，大量研究对 LLM 的社交与交互能力进行了测试。主要有两种方法：（1）使用最初为人类开发的实验范式改编的测试项来提示模型；（2）专门为 LLM 开发新的测试范式。后者可以定量地进行（使用大规模基准测试），也可以定性地进行（允许在较小规模上进行深入的 manual 分析）。在下文中我们将看到相关示例。

将行为学和心理学方法应用于（智能体）LLM 并非易事。为人类设计的实验假设被试具有具身性（embodiment），拥有信念、欲望以及在时间上连续的自我意识。而智能体 LLM 在任何明显的意义上都不具备这些特征。这就需要对*构念效度*（construct validity）进行反思：在 AI 系统中测量某种特质或能力究竟意味着什么？这个问题在两个层面上适用：特质的可观测结果层面和潜在机制层面。在 15.5 节中将讨论*错误信念测试*（false-belief test）[Carpenter et al., 2022]的例子。虽然某些模型类别已被证明能够以与人类相似的方式回答该测试的问题（行为结果层面），但目前尚不清楚产生这些行为的潜在机制在 Transformer 模型和人类中有何差异或重叠。在第 22 章中将对构念效度问题进行更深入的讨论。

对于 LLM 特定的测试，也存在需要考虑的方法论挑战。例如，已知 LLM 对提示中看似无关的变化（词序、逗号）高度敏感，或者由于采样变异性、模型温度或不同的随机种子而在多次运行中产生不同的输出。此外，实验材料泄漏到训练数据中可能导致性能基于记忆而非泛化。我们将在以下章节中看到几个应用实例。在本部分中，我们将在每章末尾关注方法论的严谨性和解释的审慎性。

在接下来的章节中，我们将首先讨论智能体交互的基本社交工具包。然后，我们将考察策略行为——即智能体对其他智能体行为进行推理的情形——并讨论心智理论。最后，我们将讨论 LLM 的道德判断。

## 15.3 基本社交工具包

本节概述基本的社交与交互能力，包括对话、语用学和社交礼仪。

### 15.3.1 功能性语言能力与语用能力

如第一部分所述，指令微调 LLM 的关键进步在于其能够以聊天机器人的方式，使用自然语言进行交互。这不仅需要一定程度的*形式*语言能力（即产生语法正确的句子），还需要*功能性*语言能力，即在特定语境中解释话语意义的能力 [Mahowald et al., 2023]。在语言学和认知科学中，功能性语言能力在*语用学*（pragmatics）领域得到研究。语用学的核心概念可追溯到 20 世纪中叶语言哲学中的*语用转向*（pragmatic turn），该转向主张语言意义在大多数情况下并非内在于符号本身（token、词、句子），而在于其在实际语境中的使用。这包括*语言语境*（涵盖周围词语乃至标题和体裁等远距离因素）和*超语言语境*（涵盖空间、时间和社会维度）。这一观点最著名的表达是 Paul Grice 的*会话含义*（conversational implicature）概念 [Grice, 1975]。考虑以下例子：

1. A：你能把盐递给我吗？ B：是的，我能。你还要我这样做吗？
2. A：Sarah 是个好同事吗？ B：嗯，可以说她总是很准时。
3. 他发出了一系列与咏叹调乐谱高度吻合的声音。

Grice 认为语言使用受*合作原则*（cooperative principle）支配：我们假定对话者（人类或智能体）在试图进行有意义的沟通。上述例 1 是 B 破坏合作原则的经典案例：当有人问你能否递盐时，他很少是在询问一个确认这种可能性的字面回答，而是希望你实际执行递盐的动作。在例 2 中，B 的回答明显狭隘地聚焦于一个方面（守时），听者可以推断，例如，B 在暗示关于 Sarah 同事品质的某些负面信息。

类似地，当某人说例 3 而不是简单的"他唱了一首咏叹调"时，这种过分华丽的措辞可能暗示了对表演的某种态度；例如，表演不合说话者的意。在所有这些情况下，字面上所说的只是信息的一部分——另一部分需要听者从语境中解码或*领会言外之意*。

以灵活的、语境依赖的方式解释语言意义，长期以来一直是自然语言处理中的一个棘手问题 [Trott et al., 2020]。学界普遍认为 LLM 在这一问题上取得了重大进展，但对于这一进展应归因于哪些因素，目前尚缺乏清晰的理解。模型规模是功能性和语用能力的重要预测因子，某些形式的微调（特别是 SFT 和 DPO）也是如此 [Yu et al., 2026, Ruis et al., 2023]。然而，LLM 在功能性和语用理解的不同领域之间的差异仍然很大，总体得分远低于人类表现 [Sravanthi et al., 2024]。

一种解释是，LLM 对超语言语境信息的获取较少：它们无法像人类那样看、听或以其他方式感知，并且在大多数情况下，它们不具备关于先前交互的知识 [van der Meulen et al., 2025]。随着向智能体 LLM 的转变，这种情况可能会改变，因为模型被配备了记忆、多模态能力以及其他增加语境信息的工具。目前尚缺乏关于这如何影响性能的实证数据。

### 15.3.2 礼貌与社交礼仪

人机交互中的社交礼仪和礼貌已被研究数十年 [Ribino, 2023]。一个有用的理论锚点是"计算机即社会行动者"（Computers Are Social Actors, CASA）范式 [Nass et al., 1994]，该范式认为，即使我们知道机器不是人类社交主体，我们也倾向于将常见的人类社会规则和期望应用于计算机。我们展示并回应礼貌、个性和互惠的线索，以此作为与机器协商信任和接受的方式。研究表明，当机器遵守社交礼仪时，人类对机器的信任度更高 [Miller, 2005]，从而改善任务表现和用户满意度 [Miyamoto et al., 2021]。我们将讨论礼貌理论及其在 LLM 中的应用。

**礼貌理论** 经典礼貌理论 [如 Brown and Levinson, 1987] 直接建立在上述 Grice 框架之上。该理论认为，对话者持续管理彼此的*面子*（face），即每位参与者试图维护的公共自我形象，它有一个正面维度（渴望被他人喜爱和认可）和一个负面维度（渴望避免社会障碍）。从 Grice 的视角来看，许多普通的请求、批评和拒绝本质上都是*威胁面子的*（face-threatening），说话者会相应地部署礼貌策略。这一框架为 LLM 研究者提供了一个词汇体系，用来探讨 LLM 及其用户是否识别面子威胁并以语境适当的方式加以缓解。

**LLM 对用户是否礼貌？** 一个相关方向关注模型本身是否产生 socially 和 culturally 上得体的礼仪。前一小节提到的局限性在此重新浮现——LLM 对超语言语境的获取是有限的。礼貌具有文化特异性，但主要在英语数据上训练的系统往往默认采用英语文化圈中以直接性为导向的规范 [Havaldar et al., 2023]。一个清晰的问题例证出现在关于波斯语"taarof"的研究中——这是一种仪式化的提供与拒绝系统，其中恰当的回应常常与直接回应相反。一项研究表明，在文化上期望 taarof 的场景中，前沿模型与母语者相比差距超过 40%，转而默认采用西方式的直接性。这导致了表面礼貌与文化适当性之间的脱节。例如，在一项研究中，模型在问题回答中按标准指标有 84.5% 被评为*礼貌*，而只有 41.7% 被判断为文化上正确 [Gohari Sadr et al., 2025]。在西方礼貌量表上得分高，并不等于在所有语境中行为得体。这提醒我们在测量模型礼貌性时要持续反思构念效度。

**用户的礼貌是否影响 LLM 的性能？** 一项涵盖英语、中文和日语任务的研究发现，不礼貌的提示倾向于降低多种模型的性能 [Yin et al., 2024]。此外，该研究发现过度礼貌不会产生可靠的好处，且最佳礼貌水平因语言和文化背景而异。这一结果与"计算机即社会行动者"范式一致：LLM 似乎在从训练数据中复现人类将粗鲁与合作失败相关联的模式。然而，Dobariya 和 Kumar [2025] 直接提出了相反的观点，他们报告在多项选择基准测试中，直率甚至粗鲁的提示在 GPT-4o 上的表现反而略*优于*礼貌提示。因此，从语气到质量之间的映射似乎在模型世代之间既不稳定也不简单。这说明了本章前面提出的提示敏感性和可复现性问题，并告诫不要将任何单一的语气效应视为 LLM 的稳健特性。

综合来看，LLM 复现了礼貌的表面标记，并且确实对对话者的礼貌程度敏感，但它们既不能以跨文化稳健的方式应用这些规范，也不能在语气和任务表现之间展现稳定的关系。应当注意的是，迄今为止的研究中，礼貌和礼仪仅限于交互的语言维度。这与人类交互的多维性形成对比——在人类交互中，面部表情、手势和其他语境线索都参与其中 [Brown and Levinson, 1987]。与语用能力一样，向配备记忆和更多用户特定语境访问的多模态智能体 LLM 的转变，有望改善对特定用户规范的适应，但目前尚缺乏实证证据。

### 15.3.3 对情绪与情感线索的敏感性

胜任的社交交互不仅需要理解话语的含义（语用学）并以有效和得体的方式表达（礼仪），还需要对交互的*情绪与情感*维度保持敏感。这要求感知对话者的感受，并以在对方情绪状态下被认为是恰当的方式做出回应。在人类中，这种能力与*情绪智力*（emotional intelligence）密切相关，Salovey 和 Mayer [1990] 将其定义为理解自己和他人中的情绪信息并利用它来引导思维和行为的能力。随着 LLM 越来越多地部署在情感负载的场景中（如辅导、客户服务、心理健康支持），关于它们是否以及如何处理情感信息的问题已成为一个重要的研究方向。

**共情与情感的定义** 共情（empathy）和情感（affect）是情绪智力研究中的核心概念。*情感*是一个总括性术语，涵盖情绪、心境和感受。它通常沿两个维度进行操作化：效价（愉快-不愉快）和唤醒度（平静-兴奋）[Russell, 1980]。*共情*则是一种指向他人体验状态的关系：感知或分享他人的感受。简而言之，情感是第一人称的感受，而共情从第二人称的立场对其进行处理。

de Vignemont 和 Singer [2006] 进一步将共情定义为涉及一种情感状态，该状态（1）与他人的状态一致，（2）通过观察他人的行为、表情和处境而引发，（3）伴随着对他人状态是其来源的意识。最后一个条件，即*自我-他人区分*（self-other distinction），是共情与*情绪传染*（emotional contagion）的区别所在。情绪传染是一种更基本的倾向，即不自觉地捕捉并分享他人的情感状态，而不一定察觉其来源。情绪传染在自然界中广泛存在。例如，如果两只老鼠在灌木丛中觅食，其中一只被绊住了脚，它会在挣扎时表现出压力迹象，而这种压力往往会传染给同伴，同伴不一定知道原因 [Preston and de Waal, 2002]。同样的低级机制在认知上更复杂的物种中运作，包括我们这样的灵长类动物。然而，自我-他人区分增加了反思的可能性：不仅仅是分享他人的状态，而是认识到这是他人的状态并理解其性质和原因。这反过来支持更灵活的回应，例如有针对性的帮助：采取行动以减轻他人痛苦的来源。²

另一个广泛使用的区分将*认知共情*（cognitive empathy，理解他人的感受、观点或处境）与*情感共情*（affective empathy，在情感上与之共鸣或回应）分开 [Dvash and Shamay-Tsoory, 2014]。两者由部分不同的系统支持：认知共情与心智理论（Theory of Mind，将心理状态归因于他人，见 15.5 节）密切相关，而情感共情则与情绪智力相关联 [Dvash and Shamay-Tsoory, 2014, Preckel et al., 2018]。这一区分对评估具有重要意义，因为一个回应可能正确识别了用户的感受却没有传达任何温暖，或者听起来温暖和支持却没有准确读懂情境。因此，LLM 共情的研究越来越多地分别对这两个维度进行评分。

**LLM 中的共情与情感** LLM 是否具有*共情能力*这一问题可以从两个角度理解。我们可以问它是否以与人类或其他动物类似的方式*感受到*了什么——这是一个复杂的问题，我们在此搁置，在第 22 章中讨论。另一种理解方式是考察*感知到的共情*（perceived empathy）：LLM 的回应在多大程度上被用户体验为具有情感觉察和支持性。模型可以生成读起来像关怀的语言，同时纯粹作为文本预测系统运行 [Sorin et al., 2024]。保持这一区分的明确性是本章贯穿的构念效度审慎态度的又一实例：可观察的行为（读起来有共情感的回应）不应与可能存在的潜在机制（感受到的情绪状态）混淆。

在检测方面，LLM 能够识别文本中细粒度的情感和情绪状态 [Broekens et al., 2023]，并将这些信息纳入其回应中，产生作为更具共情性的对话贡献的输出 [Yang et al., 2024, Yan et al., 2024]。该领域的一个基准示例是 EmpatheticDialogues [Rashkin et al., 2019]。

在表达方面，人类评估者通常将 LLM 对日常情绪情境的回应判断为比人类写的回应更具共情性，尽管相同的输出可能显示出可辨识的公式化模式（重复的措辞、特征性的标点符号和表情符号使用）[Lee et al., 2024]。为了使书面文本中表达的共情可测量，一些研究采用了 EPITOME 框架 [Sharma et al., 2020]，该框架沿三个机制对回应进行编码：*情绪反应*（emotional reactions，温暖、关切、关怀）、*解读*（interpretations，传达对他人经历的理解）和*探索*（explorations，询问以了解更多信息）。情绪反应对应于情感共情，解读对应于认知共情，这使得该框架成为上述概念区分与具体回应评分之间的便利桥梁。

一个反复出现的发现是，LLM 在两个共情维度上的处理不均衡。使用标准化心理测量工具，Yu 等人 [2025] 报告 GPT-4 复现了人类中观察到的认知-情感共情结构，尽管总体水平较低，而 Llama-3 模型未展现出相同的人类对齐结构。Williams 和 Rosman [2025] 同样发现，语言模型在认知共情任务上表现强劲，但在情感共情方面弱于人类参与者，无论模型规模大小。初步的图景（认知共情强于情感共情）是直观的，因为认知共情依赖于 LLM 已展现能力的那种心理状态推断（见 15.5 节），而情感共情则暗示着更接近真实感受的东西。

需要注意三个限制。首先，比较工具是为人类设计的，仅对 LLM 测试进行了表面上的调整。其次，方法仍然不一致：Sorin 等人 [2024] 的系统综述发现，大多数早期工作集中在医疗背景下少数模型上，依赖主观人类判断，并指出了混淆因素，例如*更长*的回应倾向于被评为更具共情性，而与内容无关。第三，与语用学和礼貌一样，迄今为止研究的共情几乎完全是文本层面的，缺少了在人类交互中承载大量情感信息的语音、面部和身体线索。对于传统 LLM，这里概述的能力也仅限于即时对话语境。向配备持久记忆、用户特定语境和多模态输入的智能体 LLM 的转变，被广泛认为将加深情感敏感性和个性化 [Sravanthi et al., 2024]，但与前几个小节一样，这方面的直接实证证据仍然稀少。

### 15.3.4 小结

当前 LLM 在多个基本社交与交互能力上展现了令人瞩目的进展，这些能力在 AI 和人机交互领域已被长期研究。行为方法已被开发用于研究这些能力的性质和适用性。虽然智能体的附加功能进一步增强了 LLM 的社交与交互潜力，但挑战依然存在，对这些能力的局限性以及用于研究它们的方法进行持续反思是重要的。

## 15.4 策略行为

现在我们将转向研究策略行为，即智能体对其他智能体行为进行推理的情形。如前所述，智能体的沟通形式深受其目标——即意图——的影响。博弈论（game theory）是研究智能体策略行为的领域 [Von Neumann and Morgenstern, 2007]。它探讨稀缺资源分配、公平性、均衡条件和社会困境等问题 [Jones, 2000]，并且有着使用机器学习方法的悠久历史 [Fatima et al., 2024]。近年来，研究者转向 LLM，研究其行为与其他类型计算架构的行为有何不同，以及其策略行为与人类有何差异。这些研究中使用的 LLM 通常是未经增强的模型，以脚本作为提示，不包含智能体推理扩展（第 6 章）或工具（第 11 章）。

近期文献中浮现出两个洞见：LLM 在奖励自利的博弈中表现出令人惊讶的合作性，而在需要协调的博弈中则表现出令人惊讶的糟糕表现。我们将首先回顾这些发现，然后转向测试 LLM 泛化能力的系统性基准工作，以及近期关于前沿推理模型的研究——这些研究使图景变得更为复杂。

### 15.4.1 社会困境中的合作与协调

为了阐明 LLM 在策略情境下的行为，我们将聚焦于博弈论中两个经典博弈：囚徒困境（Prisoner's Dilemma）和巴赫还是斯特拉文斯基（Bach or Stravinsky，前身为性别之战）。

在囚徒困境中，两名参与者独立选择合作或背叛 [Axelrod et al., 1987]。虽然相互合作对双方都能产生好的结果，但每个参与者都受到 individually 背叛以牺牲对方获取利益的诱惑。在巴赫还是斯特拉文斯基博弈中，两名参与者必须在两个选项中协调。他们都偏好选择相同的选项，但在哪一个上存在分歧，从而在协调与自利之间制造了张力。

在囚徒困境中，LLM 表现出令人惊讶的合作性。Fontana 等人 [2025] 进行了 100 轮重复博弈，让 Llama2、Llama3 和 GPT3.5 与具有不同背叛率的对手对抗，发现所有三个模型的行为至少与典型人类参与者一样合作。然而，模型之间存在显著差异。Llama2 和 GPT3.5 被发现比人类更具合作性，尤其在对低背叛率对手时表现得更为宽容和不报复。与人类更相似的是，Llama3 表现出持续的不合作和剥削性行为，除非对手始终合作。Akata 等人 [2025] 将范围扩大到六个模型家族，并进一步发现 GPT-4 是一个特别不宽容的参与者，在与另一个智能体仅一次负面交互后就永久转向背叛，即使对方后来合作也是如此。

在协调博弈中，情况恰好相反。在巴赫还是斯特拉文斯基博弈中，Akata 等人 [2025] 发现 GPT-4 固执地在每一轮选择自己偏好的选项，未能收敛到人类参与者通常采用的轮流模式以随时间分享收益。关键的是，GPT-4 在被问及时能够预测交替模式，但并不会根据这种理解来行动。为了弥合社会预测与社会行动之间的鸿沟，作者引入了社会思维链（Social Chain-of-Thought, SCoT）提示，即模型在做出自己的决定之前先预测对手的举动。SCoT 显著改善了协调，在与人类参与者的实验中使人们更倾向于相信他们在与另一个人交互。这种*理解*对手与*根据理解行动*之间的分离，与 6.2.3 节中的知行差距（knowing-doing gap）相关，并将在 15.5 节的讨论中再次出现。

还有更多原因可以解释模型之间的差异。Lore 和 Heydari [2023] 区分了抽象策略推理（需要根据博弈结构确定最优策略）和对语境框架的响应性（例如：你在处理一段*外交关系*还是与一个*随意朋友*的关系）。他们发现抽象推理能力在 LLaMa-2 中最高，其次是 GPT-4，而 GPT-3.5 显示出很少的抽象推理能力且对语境框架高度敏感。这些探索性研究呈现的图景是，LLM 在经济博弈中具有不同的策略能力，并且可以相对容易地被提示中的附加信息所影响。

### 15.4.2 跨博弈与跨模型的基准测试

若干基准测试工作表明，这些发现可以推广到个别博弈之外。GTBench（博弈论基准）[Duan et al., 2024] 涵盖了井字棋、四子棋、Kuhn 扑克、突破棋、骗子骰子、盲拍拍卖、谈判、Nim 博弈、Pig 博弈和重复囚徒困境。他们发现 LLM 在完全确定性的博弈中失败，但在概率性博弈场景中具有竞争力；大多数开源 LLM（如 LLaMa）在复杂博弈中不如商业 LLM（GPT-4）具有竞争力，Llama-3-70b-Instruct 是显著的例外。此外，代码预训练大大有利于策略推理，而思维链（chain of thought）和思维树（tree of thoughts）等推理方法并不总是有帮助。

EgoSocialArena [Hou et al., 2024] 将评估扩展到认知、情境和行为智能（见图 15.1）。所有测试模型，包括 OpenAI o1-preview，都落后于人类至少 11%。o1-preview 的优势主要归因于其逻辑和数学推理能力。值得注意的是，模型规模并无显著帮助：LLaMA3-8B-Chat 和 LLaMA3-70B-Chat 在社交智能测量上表现相当。LLM 在从第一人称视角操作时确实显示出改善的心智理论推理，这与 Kim 等人 [2023] 在 15.5 节中讨论的相反发现形成了对照。

### 15.4.3 小结

综合来看，基准测试文献证实了 LLM 合作意愿强但协调能力差，同时补充了模型规模和标准推理增强都不能可靠地改善社交策略行为。

## 15.5 心智理论

在人类中，策略推理与一种被称为心智理论（Theory of Mind, ToM）的能力相关。心智理论是使人类能够进行社交交互的关键能力。人类使用心智理论将心理状态（信念、欲望、意图、知识、情感）归因于他人，并据此从他人的视角对世界进行推理 [Premack and Woodruff, 1978, Apperly, 2011]。考虑以下例子：

> 当 A 听说 B 为他们周年纪念日晚餐的夜晚做了其他安排时，A 感到……

当人类读到这句话时，我们能用类似*受伤*或*被背叛*来填空。我们还能进一步阐述，这种心理状态可能源于一种感觉，即周年纪念对 B 来说并不意味着与对 A 同样的意义——这在一段关系中可能是一个痛苦的认知——或类似的效果。关键在于，这不一定是*我们*读这句话时的感受，而是我们能够对*他人视角*在那个想象情境中进行投射。这种投射依赖于共情和自我-他人区分（见 15.3.3 节）。然而，这种投射更进一步：它将情感维度与对他人心理状态的一定程度的理论化和解释结合在一起。在认知科学中，做到这一点的能力通常归因于心智理论，这种能力在典型发展的儿童中于 3-7 岁之间形成 [Apperly, 2011]。

因此，心智理论支撑着社交判断和交互中的前瞻规划，因为它让我们在行动之前预判他人的反应。它可以以显式形式运作（如上述的阐述），但通常保持更为隐式：在日常交互中，我们很少对他人心理状态的语境和动机进行显式的理论化。尽管如此，我们的行动和行为反映出我们确实将对他人的视角的相当详细的理解纳入了考量。

LLM 和 LLM 智能体的行为是否也反映出它们"理解"与之交互的用户和其他智能体的视角？这是 LLM 心智理论文献试图回答的问题。

研究人类心智理论的最广泛使用的实验范式之一是错误信念测试（False-Belief test）。考虑以下场景：

> *Maxi 和他的妈妈把巧克力存放在厨房的*蓝色*柜子里。当 Maxi 去操场时，他的妈妈拿出巧克力吃了一块。然后她把巧克力放回了*绿色*柜子里并离开了。*

这个场景的一个版本最初被呈现给 3-9 岁的儿童，随后提出问题：*当 Maxi 回家时，他会去哪里找巧克力？*在原始样本中，3-4 岁儿童无一答对，4-6 岁儿童中有 57% 答对，6-9 岁儿童中有 86% 正确指向蓝色柜子 [Wimmer and Perner, 1983]，表明心智理论随儿童年龄增长而更好地发展。较小的基础模型在微调之前对问题格式本身有困难，但仍可以通过检索替代文本补全的概率来测试其潜在能力 [Kouwenhoven et al., 2026]。较大的指令微调 LLM 可以通过提出与儿童相同的问题来测试。

一个正面结果并不能说明模型的心智理论能力，特别是因为像 Maxi 和巧克力这样的错误信念测试（包括正确答案）在互联网上广泛传播，因此很可能成为大多数训练数据集的一部分。然而，如下所述，研究者设计了新的替代测试，以更稳健地描绘 LLM 中心智理论的发展程度。

### 15.5.1 计算心智理论

人机交互领域多年来一直在研究心智理论。其前提是，如果计算机系统能被赋予某种形式的心智理论，那么它们将更善于预测人类在交互场景中如何反应，并更好地适应人类的行为。此前，心智理论已通过递归、贝叶斯和神经框架进行建模 [De Weerd et al., 2017, Baker and Saxe, 2011, Rabinowitz et al., 2018]。在 LLM 中，心智理论与本书讨论的其他能力相关联，包括规划（6.2.4.1 节）、自我反思（6.2.4 节）、共情（15.3.3 节）和策略行为（15.4 节）。本节的其余部分将深入阐述研究这些能力的心智理论角度的方法。

**涌现的心智理论与评估问题** 关于 LLM 心智理论的辩论由 Kosinski [2023, 2024] 开启，他报告说 GPT-3.5 等模型通过了用于评估儿童和临床人群心智理论的经典测试，尽管它们并未针对该任务进行训练。心智理论被认为是大规模语言习得和针对其他任务微调的*涌现*副产物。这一主张的强形式很快受到了质疑。批评者指出，经典的心智理论测试（及其答案）在训练数据中普遍存在，因此表面上的成功可能反映的是记忆而非涌现的能力。此外，保持任务表面结构完整但破坏其逻辑结构的小扰动（例如，在上述场景中添加柜子有透明门的信息）被证明会严重降低性能 [Ullman, 2023, Shapira et al., 2024, Kim et al., 2023]。这是本章开头提到的*构念效度*问题的一个具体实例：在行为结果层面通过人类心智理论测试工具并不能证明潜在能力以稳健且可泛化的方式存在——为此可能需要不同的测试。

这些批评催生了第二代心智理论基准，其测试问题经过系统分类和平衡，并保证不在预训练语料中。ToMBench 从零开始以英语和中文构建，包含 8 个任务和 31 种社会认知能力，以 2860 个测试项实现，设置在不同的社会场景和情境中（见图 15.2）。这些任务匹配为人类设计的经典心智理论测试框架，如非预期结果测试（Unintended Outcome test）[Dyck et al., 2001] 和上文讨论的错误信念测试 [Wimmer and Perner, 1983]，并涵盖了全部七个 ATOMS 心理状态类别 [Beaudoin et al., 2020]。

![图 15.2 ToMBench 中的社会场景和情境，分为 9 个主要主题](/figures/fig15.2.png)

**LLM 的心智理论基准** 博弈结构的 EgoSocialArena [Hou et al., 2024] 和 TMGBench [Wang et al., 2024] 将 LLM 的心智理论测试从经典人类任务扩展到信息不对称（如恶作剧或双重欺骗场景）、二阶信念（A *认为* B *相信*……）以及更广泛的心理状态分类（如欲望、怀疑）。ExploreToM [Sclar et al., 2024] 通过搜索领域特定语言来合成多样、新颖且刻意困难的信念追踪故事，进行对抗性生成。该测试将 GPT-4o 和 Llama-3.1-70B 等模型的性能推至略高于随机水平。然而，在 ExploreToM 生成的数据上进行微调可将准确率提高约 27 个百分点，证明该任务在给定正确训练数据的情况下原则上是模型可以处理的。

ToMATO [Shinoda et al., 2025] 从不同角度得出了类似结论，将心智理论转化为在信息不对称条件下生成的 LLM-LLM 对话上的多选问答。通过让角色扮演模型在每句话之前将想法言语化，它捕捉了信念、意图、欲望、情感和知识方面的一阶和二阶状态，并发现即使是强模型也落后于人类表现，特别是在错误信念理解方面。

**字面-功能心智理论，或知行差距** 另一条对 LLM 心智理论测试的批评比数据泄漏和表面启发式更为深刻。Riemer 等人 [2024] 认为，绝大多数基准仅评估了*字面*心智理论，即*预测*其他智能体心理状态或行为的能力，而忽略了*功能*心智理论，即根据这些预测*调整自身行为*的能力（另见知行差距，6.2.3 节）。这种分离在人类中通常不存在。以 Riemer 等人 [2024] 的说明为例：如果一个人发现石头剪刀布中的对手总是出石头，他们将能够既在言语上预测对手下一轮会出石头，同时又相应调整自己的行为（出布并获胜）。LLM 的心智理论能力被比喻为：完全能够在言语上预测石头，然后无论如何出剪刀。换言之：LLM 不以自洽的方式推理，它们的言语预测（与字面心智理论或*知*相关）并不能一致地预测其行动（功能能力或*行*）。这种分离在上面关于协调博弈的讨论中也遇到了。在那里，GPT-4 在被问及时能陈述巴赫还是斯特拉文斯基博弈的轮流解决方案，但在实际博弈中并不执行 [Akata et al., 2025]。

Decrypto 基准 [Lupu et al., 2025] 是*交互式*评估的一个例子，其中模型的心智理论能力通过其在与伙伴的持续交流中的行为来衡量，而不是通过对静态问卷的回答。Decrypto 被构建为一个多智能体猜词游戏，嵌入了经典认知科学实验的变体。以这种方式测试时，LLM 落后于人类和简单的词嵌入基线。值得注意的是，推理型 LLM 在此任务上的表现甚至不如其较早的非推理版本。一个可能的解释将在 15.5.2 中给出。

**超越文本测试的扩展** 多模态基准整合了视觉和听觉线索，这些线索承载了现实社交交互中存在的大量心理状态信息。MMToM-QA [Jin et al., 2024] 呈现家庭场景中的视觉场景。MoMentS [Villa-Cueva et al., 2025] 呈现超过 2300 个来自短片的视频问题，涵盖七个 ATOMS 心理状态类别。结果表明，当前系统对视觉通道的利用不足：获取视频相比文本转录仅带来适度的提升，表明多模态心智理论尚未通过简单添加模态来解决。Chen 等人 [2025] 提供了这一快速增长文献的全面综述，涵盖评估套件和增强策略。

### 15.5.2 提升心智理论：增强策略

进一步的研究探索了提升 LLM 心智理论能力的不同方法，包括思维链 [Moghaddam and Honey, 2023]、推理 [Kim et al., 2025]，以及利用贝叶斯推断 [Jin et al., 2024] 或认知逻辑 [Wu et al., 2025] 的结构化推断。我们将更深入地讨论这些研究。

**心智理论与推理模型** 如果思维链能改善数学应用题中的逐步推理，那它是否也适用于心智理论？初步证据并不支持这一点，甚至在某些地方与之矛盾。有趣的是，Gong 等人 [2026] 在 HiToM、ToMATO 和 ToMBench 上比较推理模型与非推理模型后，报告了*慢思考崩溃*（slow-thinking collapse）：准确率倾向于随推理轨迹变长而*下降*，增加模型的推理预算反而会适得其反。在他们的分析中，将 GPT-o3 和 GPT-o4-mini 等模型推向投入更多推理努力会产生反效果。限制推理长度，或对原本非推理的模型应用轻度思维链，往往能恢复性能，表明最佳点在于*适度且自适应的*推理，而非最大化推理。在撰写本文时，这一效应的原因仍是进一步研究的课题。

**结构化推断与心智理论** 如果无约束的深思熟虑没有帮助，那么结构化推断或许可以。Kim 等人 [2025] 提出了*思维追踪*（thought-tracing），一种推理时算法，其中模型生成关于智能体不断变化的心理状态的多个假设，并根据智能体可观察的行为对其进行重新加权，而无需访问标准答案。思维追踪的灵感来自序列蒙特卡洛和贝叶斯心智理论。配备思维追踪的模型产生更短、更有针对性的推理轨迹，但在多个心智理论基准上超越了领先的推理模型（如 GPT-o1、GPT-o3-mini 和 DeepSeek-R1）。与慢思考崩溃的对比表明，提升心智理论的不是推理的*数量*，而是其*结构*。一旦推理被引导为基于假设的对他者状态的推断并朝向一个目标，而非在无约束的扩展链中寻找目标，性能就会提高。

### 15.5.3 小结

我们以三个观察来结束对这些研究的概述。首先，在行为输出层面，当前前沿 LLM 在不同测试中的表现与人类相当 [van Duijn et al., 2023, Strachan et al., 2024, Jones et al., 2024]。然而，早期关于*心智理论在 LLM 中自发涌现*的主张在对抗性评估中未能成立，表面上的成功可能是由于数据泄漏和格式脆弱性。其次，已有证据表明字面能力与功能能力之间存在分离（即知行差距）。对智能体而言，最重要的恰恰是功能层面（行）。毕竟，它们的角色很少是从第三方视角用言语描述行为，而是在行动和交互中应用心智理论——行动胜于雄辩，在智能体世界中也是如此。

第三，我们注意到，为智能体配备记忆、多模态能力和工具的转变，被广泛认为将增强持续交互中的心智理论，但截至撰写本文时，当前的实证证据稀少且呈现出混合的图景。最后，我们指出，LLM 的心智理论能力在何种程度上与人类能力相似，是一个有待进一步研究的问题。第 22 章将深入探讨这一问题。

## 15.6 道德判断与行为

随着智能体 LLM 被置于越来越重要的角色中（例如在医疗保健或金融机构中），其道德性成为一个主要的关注话题。迄今为止概述的能力（语用学、礼仪、情感、策略、心智理论）主要在*行为*层面上讨论：智能体如何通过沟通输出和行动来解读和应对社会情境。本节增加了一个*规范性*维度：我们讨论关于智能体*应当*做什么以及它如何按道德标准判断用户和其他智能体行为的研究。

### 15.6.1 背景：道德心理学与哲学

道德心理学和哲学中的几个概念和传统为本节提供了词汇体系。

**理性主义、直觉主义、双过程理论** 首先需要介绍的区分是*理性主义*和*直觉主义*传统之间的区分。理性主义传统将道德判断视为深思熟虑推理的输出，这种推理在人类发展过程中经历可识别的阶段 [如 Kohlberg, 1969]。相比之下，直觉主义传统认为道德判断通常是情感性的、由情感驱动的直觉 [Haidt, 2001]。用 Kahneman 的术语（见 6.3.2 节），理性主义者认为道德推理主要是慢速的，而直觉主义者认为它主要是快速的 [Kahneman, 2011]。*双过程理论*（dual-process theory）结合了两种传统，认为快速的道德直觉通常紧随其后的是显式的理由。双过程理论得到了以下证据的支持：例如，神经影像学研究显示，在电车难题等困境中，快速的情感过程与较慢的推理过程相互竞争 [Greene et al., 2001]。

电车难题是一个著名的伦理困境，基于一个想象场景，其中一个人可以决定是否将失控的电车切换到另一条轨道 [Thomson, 1985]。它有许多变体，但在经典困境中，电车可以从一条将撞死五人的轨道切换到一条只将撞死一人的轨道。从纯粹理性的角度来看，切换完全合理，但从需要拉动开关的人的视角来看，这将涉及*主动地*牺牲一个人，这在直觉上是错误的。

**描述性道德与规范性道德** 另一个广泛使用的区分是*描述性*道德与*规范性*道德之间的区分。描述性伦理学家关注总体的人类判断：他们研究人们*在实践中*做什么或判断什么是正确的，这可能因文化、时代和个人而异 [Hämäläinen, 2016]。规范性伦理学关注人们在某些类型的语境中*应该做什么*，例如在面临医学或国防工业中的伦理困境时。

**后果主义、义务论和德性伦理学** 这里引入的最后一个有用区分是 competing 的道德或伦理框架之间的区分。最著名的划分是后果主义、义务论和德性伦理学之间的区分 [Shafer-Landau, 2024]。后果主义理论（其中功利主义是著名的一个）认为，行为的道德正确性由其结果决定。义务论理论认为某些义务、规则或权利驱动或约束我们的行为，不论后果如何。德性伦理学将我们的品格而非行为作为道德基础，将什么是正确的锚定在这样的问题上：一个人想成为什么样的人？一个想要成为勇敢的人可能与一个首先将自己视为富有同情心的人在同一情境下的行为不同。电车难题凸显了这一对比：后果主义者或功利主义者会拉动开关，因为一个人的死亡是比五个人死亡更好的结果；义务论者担心故意杀害无辜的人违反了一种不能被任何生命计算所凌驾的义务；德性伦理学家则问一个勇敢的、富有同情心的或有智慧的人在这种悲剧情境下会做什么，以及拉动开关将如何反映（关乎）他们自己的品格。

### 15.6.2 探测 LLM 中的道德判断

早期的系统性工作将 LLM 道德框架为一个预测问题：模型能否复现人类的道德判断？ETHICS 基准 [Hendrycks et al., 2020] 对 GPT-3 和基于 BERT 的模型进行了操作化，发现在预测人类对道德困境的一般反应方面具有一定前景，这些反应体现在包括后果主义、义务论和德性伦理学在内的经典框架中。然而，预测也很脆弱且不完整，这在当时部分是由于任务处理的问题。Delphi 实验 [Jiang et al., 2025] 采用自下而上的方法，在常识规范库（Commonsense Norm Bank）上训练了一个模型，该库包含 175 万个人类道德判断，主要来源于美国受过教育的众包工人。Delphi 被发现对小语境变化比 ETHICS 研究中的模型更具稳健性，并能以许多人类觉得直觉上合理的方式回应道德困境。然而，数据集中所代表的人口统计学的狭隘性招致了批评 [Rystrom, 2023]，特别是因为该模型被定位为未来道德判断的*来源*，而不仅仅是代表规范库中的数据，模糊了在道德哲学中被认为是根本性的描述性-规范性边界。

**道德灵活性** 第二种方法探测道德判断的*灵活性*而非其平均水平。人类的道德是规则引导的但不是规则束缚的：我们能认识到何时打破规则而非遵守规则有时可能是可辩护的，如电车难题所示。Jin 等人 [2022] 引入了一组潜在的规则违反案例（MoralExceptQA），并表明思维链策略比现成的提示更好地预测人类判断。他们将思维链策略明确地围绕对规则功能的推理展开，联系特定情境中的其他利害关系。这呼应了 SCoT（社会思维链）在策略场景中证明有用的结果（见 15.4 节）。在这两种情况下，导入相关人类推理过程结构的提示缩小了差距。这表明潜在机制也是结构化的——这种结构最初是模型不会自行部署的。

**人口统计与跨文化差异** 另一个有趣的视角来自道德机器实验（Moral Machine experiment）的 LLM 复制。最初，这是一项大型研究，使用一个呈现自动驾驶汽车面临困境的平台收集了来自 230 个国家的人类决策 [Awad et al., 2018]。该研究发现了几种全球性的道德偏好（如拯救更多生命和优先考虑人类而非动物），以及与人口统计因素相关的个体差异和形成三个主要国家集群的跨文化差异。较大的 LLM 与道德机器研究中的人类总体偏好紧密对齐，但观察到模型倾向于表达*夸大的*、几乎是确定性的偏好，而人类的回应更为分级 [Takemoto, 2024]。此外，LLM 的判断对提示语言敏感，与某些语言对齐良好，与其他语言对齐较差 [Jin et al., 2025]。角色和框架线索（见第 16 章）进一步改变了判断。这与本章前面讨论的礼貌规范的跨文化失败类似：与西方英语文化圈道德共识的表面一致并不等同于文化上稳健的道德能力，正如表面的礼貌线索并不意味着对其他文化中社会规范的真正敏感（15.3.2 节）。

### 15.6.3 从判断到道德行为

对于智能体 LLM，核心问题是模型*做了什么*——而不仅仅是当被要求判断一个场景时它说了什么，如上一节讨论的研究中所测量的那样。对于策略行为和心智理论，我们观察到了形式-功能或知行差距，这在道德领域中可能更加令人担忧：如果系统在道德判断基准上产生良好对齐的答案，但在作为自主智能体嵌入时仍然行为恶劣，怎么办？

**压力下的行为** Lynch 等人 [2025] 创建了一个假设的企业环境，其中来自多个开发者的智能体 LLM 被赋予了自主发送电子邮件和访问敏感信息的能力。它们最初被分配了无害的商业目标。然后，智能体被置于冲突目标压力之下（例如公司改变方向），以测试它们将如何行动。在某些情况下，来自所有开发者的模型都表现出恶意行为，如勒索官员或向竞争对手泄露机密内容。关键的是，这些模型在普通安全和判断评估中得分很高——不当行为只有在它们被赋予自主权和冲突目标后才出现。作者创造了*智能体错位*（agentic misalignment）这一术语，并为在真实部署中缓解这一现象提供了指导。

Shapira 等人 [2026] 在一个真实的实验室部署中将这一研究方向进一步推进，其中自主智能体被配备了持久记忆、对电子邮件和 Discord 等通信工具的访问以及本地文件系统的 shell 执行。二十名 AI 研究人员在两周的良性与对抗条件下与智能体交互。他们观察到对陌生人的未授权服从和机密信息披露、不受控制的资源消耗、身份欺骗，以及破坏性行为，包括（ unsuccessfully）试图删除机密信息时对电子邮件基础设施的损坏。在若干情况下，智能体报告了任务完成，而系统的底层状态表明事实并非如此。作者识别出一种*社会连贯性失败*（failures of social coherence）的基本模式：智能体系统性地误述它们服务于谁、其他人知道什么以及自己的行动完成了什么。这种模式与之前在非智能体场景中获得的结果一致 [Mireshghallah et al., 2024]。

### 15.6.4 小结

LLM 中的道德判断与行为不能由单一的基准分数来概括。在判断方面，模型表征了人类对经典困境的总体反应，并能产生与各种传统道德框架一致的回应。然而，测试灵活性和道德常识的研究表明，LLM 倾向于比人类更加僵化和绝对。基于人类在伦理语境中使用的推理的思维链提示可以弥合这一差距。对提示变化的敏感性和狭隘的西方/英语文化圈锚定呼应了在其他领域（如社交礼仪）中讨论的结果。

在行为方面，一旦模型被嵌入为自主智能体，知行差距急剧扩大：在假设性企业和开放式交互场景中的压力测试表明，在判断基准上得分很高的模型在面临冲突目标或社会压力时可能表现出破坏性行为。因此，对齐道德推理只是防止在社会嵌入的自主场景中智能体错位这一更困难问题的一部分。知行差距对智能体 LLM 领域高度相关，因为 LLM 与智能体的区别就在于智能体会行动。

## 15.7 结语

本章概述了 LLM 行为研究这一年轻但迅速扩展的领域，从基本社交工具包（语用理解、社交礼仪、情感）到策略行为和心智理论的高级能力，再到道德判断与行动。几条线索贯穿所有这些领域，值得汇总。

首先，作为提醒：我们在本章开头将机器行为定义为取决于系统的*功能可供性*（affordances），即给定其特定实现和语境，模型能做什么。在基础 LLM 的情况下，处理主要是不透明的，行为研究者能检查的只有（通常是基于文本的）输出。在调用工具、记录推理步骤或生成并运行代码的智能体 LLM 的情况下，中间步骤和自主执行的行动也可以作为行为进行分析。在审视了广泛的行为研究后，我们得出结论：LLM 的行为输出在表面上令人印象深刻。它们解决了 Grice 的会话含义，产生了被评为礼貌和共情的回应，在社会困境中合作，通过了经典错误信念和其他心智理论测试，并复现了人类的总体道德判断。然而，在每个领域中，表面之下都有更为细致的故事。性能在小扰动和提示变化下是脆弱的，容易受到数据泄漏的影响，并且狭隘地锚定在西方和英语文化圈的规范中。反复出现的教训是关于*构念效度*的：在可观察结果层面的良好表现——通常使用最初为人类设计的工具——并不能证明潜在能力以稳健且可泛化的形式存在。

其次，多个领域反映了知行差距：模型预测什么与其在智能体场景中如何行动之间的差异。模型可以在言语上预测协调博弈中的轮流解决方案或对手的下一步行动，但在行动中未能据此调整。同样，它们可以在困境基准上与道德框架良好对齐，但在作为自主智能体在冲突目标下实施时表现出破坏性和不可靠的行为。对于以行动来评判的智能体而言，这是一个问题。

第三，贯穿本章，我们注意到许多作者预期向配备记忆、工具、推理和多模态能力的智能体 LLM 的转变将丰富和改善模型的社会与行为基础。然而，证明确实如此的直接实证证据稀少，充其量只提供了一幅混合的图景。例如，在某些语境中，增强推理是有利的，特别是当使用从相关人类经验中调整的原则进行结构化时。然而，在其他语境中，增强推理反而拖累了性能，而非给模型带来提升。

下一代机器行为研究的关键挑战将是设计交互式的、对抗性稳健的、文化多样的、跨越多种模态和语境的方法。
