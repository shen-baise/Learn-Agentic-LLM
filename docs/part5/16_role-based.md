# 多 LLM 系统中基于角色的交互

> **本章学习目标**
>
> 在本章中，你将学习多个 LLM 智能体在被分配角色并组成群组进行交互时的行为方式。具体而言，你将能够：
> - 区分*基于角色的*多智能体交互（本章）与*开放式的*涌现模拟（第 17 章）。
> - 描述 LLM 智能体在*博弈论*环境中相互交互时的行为，并将其与单智能体的策略性发现（第 15 章）相联系。
> - 解释*基于角色的协作模式*，并识别实现这些模式的框架。
> - 批判性地评估多智能体协作在何时能提升性能、何时不能，以及多智能体交互引入了哪些新的失败模式和*安全风险*。

## 16.1 从单智能体到多智能体

上一章从行为视角研究了单个 LLM 及 LLM 驱动的智能体：单个模型如何解读沟通、社会或道德情境，并在其中采取行动。本章我们从单智能体转向多智能体场景，考察当多个基于 LLM 的智能体被置于交互环境时会发生什么——例如作为博弈论竞赛中的对手，或作为团队中的协作者。分析单元从单个模型的行为特征转向模型之间产生的交互模式与集体结果。

### 16.1.1 多智能体模拟：历史与现状

使用人工智能体来研究交互在计算社会科学中有着悠久的历史 [Epstein and Axtell, 1996, Macal and North, 2010]。传统上，具有基本感知、推理和决策能力的智能体群体在虚拟环境（或在基于机器人的模拟中为真实实验环境）中进行交互 [Steels, 1995, Shoham and Leyton-Brown, 2008]。此类模拟的目的通常是 bridging 理论与实验工作，将人工行为作为假说的试验场，用于研究那些在真实世界中难以或高成本进行实验的人类行为领域。

历史上，两个障碍限制了这一研究方向的发展：一是难以验证行为是否真实可信，二是模拟智能体社会的计算成本过高。智能体型 LLM（agentic LLM）和模拟基础设施的进展 [Rutherford et al., 2024] 正在改变这一局面。基于 LLM 的智能体能够以自然语言进行交流，可以处理丰富的背景知识，还可以被赋予差异化的角色设定（persona），使得模拟交互更具表现力，也更直接地可与人类交互进行比较。

### 16.1.2 基于角色的交互与涌现式交互

多 LLM 研究可以根据研究者对模拟的控制程度进行分类。一端是每个智能体都被分配一个*角色*，包括角色设定、目标和交互协议。研究问题通常是智能体在指定结构内的行为表现，以及由此产生的系统整体与其他指定结构和角色相比的绩效如何。另一端，智能体被置于一个开放式环境中，不预先分配角色，研究问题是会*涌现*出怎样的社会结构：群体动力学、惯例和规范。

本章关注的是这一谱系中基于角色的一端，第 17 章讨论涌现式的一端。这一区分对于方法选择和结果解读都很重要。在基于角色的系统中，角色和交互协议是设计决策或实验变量。行为的评价是相对于系统设计目标来进行的。在涌现式场景中，目标或任务处于背景位置（或完全缺失）。分析更加开放和探索性，更接近民族志而非基准测试。然而，正如后文将会明确的，这种区分并非绝对：基于角色的系统也经常出现非预期的行为。

### 16.1.3 多智能体协作的五个维度

作为本章的组织原则，我们采用 Tran 等人 [2025] 提出的 LLM 协作五维度分类框架：

1. **参与者（Actors）**：涉及哪些智能体，以及它们是同质的（同一模型的实例）还是异质的（不同模型或能力配置）
2. **交互类型（Interaction types）**：合作、竞争或两者的混合（"竞合"）
3. **结构（Structures）**：智能体的组织方式，例如点对点式、集中式或分布式
4. **策略（Strategies）**：如何激发协作，例如通过角色分配或模型级机制
5. **协调协议（Coordination protocols）**：将智能体连接在一起并调节其通信的机制

本章讨论的系统在这五个维度上做出不同的选择，牢记这些维度有助于更清楚地理解每个框架的创新之处。

### 16.1.4 方法论说明

评估多智能体系统继承了评估单个模型的所有方法论困难：提示词敏感性、测试材料可能泄露到训练数据中，以及采样变异性。此外，它还带来了新的困难：

- 报告的结果通常更难复现，因为一个智能体输出的微小变化会在后续交互中级联放大，增加了运行间的变异性。
- 性能差异的原因可能不清楚：是多智能体协作本身、协调协议、角色分配中嵌入的提示工程，还是仅仅因为多个智能体累计消耗的额外推理预算。
- 构念效度（construct validity）转移到了社会交互术语层面：诸如*团队协作*、*讨论*或*集体决策*等概念承载着丰富的人类内涵，而实际模拟可能并不具备这些内涵。

带着这些注意事项，本章首先考察最简单的多智能体场景：LLM 智能体在策略环境中面对面博弈，除了博弈本身之外不分配任何角色（第 16.2 节）。接下来，我们考察当通过定义协调协议和明确角色来简化交互时会发生什么变化（第 16.3 节）。

## 16.2 LLM 智能体之间的策略性交互

在第 15 章中，我们考察了 LLM 在被提示与脚本化对手进行经济博弈时的行为。这里我们考虑*LLM 智能体在博弈论场景中相互交互*的研究。本节中的智能体是对等的对称参与者：每个都追求自身利益，没有哪个被分配协调或监督角色。我们首先考察在多种博弈中综合评分 LLM 智能体的基准测试，然后考察围绕单一场景构建的更丰富的单个模拟平台中的行为。

### 16.2.1 跨博弈的策略能力基准测试

MAgIC 研究 [Xu et al., 2024] 使用了社交推理游戏（卧底游戏 Undercover 和变色龙游戏 Chameleon）以及博弈论场景，如费用分摊、多人囚徒困境和公共物品博弈。其目标是提取七种能力：理性、判断力、推理、欺骗、自我意识、合作和协调，如图 16.1 所示。研究在多种智能体环境中评估了现成的和增强形式的 LLM 在这些能力上的表现。GPT-o1 和 GPT-4 的得分显著优于其他模型。

LLM 通常在判断力、理性与合作方面得分较高，部分模型在欺骗方面也表现不错，但在推理方面得分较低，且除一个模型外，所有模型在协调方面得分都很低。唯一的例外是配备了概率图模型（probabilistic graphical modeling）的 GPT-o1，这是一种受 Koller 和 Friedman [2009] 启发的类心智理论（theory of mind）能力的实现。作者表明，概率图模型全面提升了 LLM 的表现。这与第 15.5 节讨论的一般证据一致，即人类在策略环境中严重依赖心智理论。

另一个以协调（而非作为多项特质之一）为研究对象的基准测试是 LLM 协调基准（LLM-Coordination Benchmark）[Agashe et al., 2025]。LLM 在两个不同的任务上被评估：纯合作博弈中的智能体协调，以及关于这些博弈的问答（见图 16.2）。实验发现，只要决策可以依赖环境变量，LLM 智能体就表现良好；但当成功需要主动推理伙伴的信念和意图时，表现就很差。具体而言，这类环境变量包括游戏布局、物体位置、每个智能体当前位置、哪些门是开的等元素。

最清晰的例证是 Overcooked-AI，这是 LLM 表现最好的游戏。该游戏是完全可观察的，其动作空间由诸如*从洋葱分配器 1 拿起洋葱*和*将洋葱放在盘子 0 上*等动作组成。在大多数场景和布局下，LLM 只需根据游戏环境状态考虑下一步最佳行动，而无需考虑其他智能体的视角。

![图 16.2 LLM 协调基准的说明](/figures/figure_16_2.png)

这种不对称性在比较 Overcooked 和 Hanabi 的表现时尤为明显。Hanabi 是一个每个动作都需要推理伙伴信念的游戏。在 Overcooked 上，零样本 LLM 智能体可以匹配甚至超过经过专门训练的深度强化学习基线模型。然而在 Hanabi 上，强化学习基线模型接近满分，而大多数 LLM 智能体几乎无法得分。最好的 LLM 智能体（基于 GPT-4-turbo）即使配备了显式心智理论推理和自我验证步骤，也只能达到最高分的大约一半。没有这些增强，GPT-4-turbo 等强模型的得分几乎完全崩溃，表明所测量的能力部分是智能体框架的特征，而非仅仅是模型本身的特征。

不过，LLM 智能体在跨游戏配对（cross-play）中表现出更强的鲁棒性：强化学习方法在与未见过的伙伴配对时性能急剧下降，而 LLM 智能体的零样本特性使其能够无损地迁移到未见过的伙伴。

该研究的问答部分（见图 16.2 右栏）将问题分解为环境理解、心智理论（ToM）和联合规划三个类别分别考察。他们发现 LLM 在第一类上总体得分较高（最佳模型超过 80%），在 ToM 上得分较低，在联合规划上得分最差（最佳模型低于 40%，开源模型低于随机水平）。这与 Overcooked（环境驱动）和 Hanabi（ToM 和规划驱动）之间观察到的得分差异一致。

纯合作博弈的关键特征是智能体之间必须完全合作，不存在竞争激励。相比之下，在囚徒困境（或 MAgIC 等基准中的混合动机博弈）等竞争性场景中，智能体面临个人收益与集体收益之间的真正张力。在这类博弈中，当 LLM 未能合作时，原因并不明确：智能体可能是不擅长协调，*或者*它可能在策略性地考虑个人收益。而在纯合作博弈中，没有任何理由背叛，因此任何合作失败都是协调能力的真正不足。

### 16.2.2 单场景平台中的策略性交互

基准测试聚合了许多小型博弈的结果。一条互补的研究路线则构建单一场景并深入研究智能体行为。

Alympics [Mao et al., 2023] 为模拟 LLM 驱动智能体之间的策略交互提供了一个受控的实验平台，其示例是一个多轮水资源分配挑战，其中稀缺的生存资源需要随时间进行分配，见图 16.3。AucArena [Chen et al., 2023a] 模拟拍卖场景，跨 LLaMa 2.13b、Mistral 7b、Mixtral 8x7b、Gemini 1.0 和 GPT 3.5/4.0 进行测试，发现 GPT-4 等最强 LLM 具备参与拍卖的技能，如预算管理和目标聚焦，但即使对该模型而言表现也有波动，作者指出仍有相当大的改进空间。

![图 16.3 Alympics 水资源分配挑战博弈](/figures/figure_16_3.png)

### 16.2.3 小结

在基准测试和单场景平台上，协调能力一致地成为 LLM 智能体的薄弱环节。更强的 LLM 在 MAgIC 的理性和判断力方面得分良好，在 AucArena 中能合理管理预算，并在环境驱动的合作中匹配经过训练的强化学习智能体。然而，除了最强且最精心搭建支架的模型外，所有模型在需要推理伙伴信念和意图时都会失败。换言之，模型无法一致地将心智理论推理*整合*到其行为中。

在第 15 章中，这类失败被称为"知行差距"或"字面-功能差距"：GPT-4 在被提示预测巴赫或斯特拉文斯基作品中的交替模式时能准确回答，但在实际演奏时却无法执行。然而，这里回顾的多智能体研究使这一诊断变得复杂。在 LLM 协调基准的问答部分中，关于联合规划的问题恰好对应智能体在游戏每一步面临的决策。正是在这些问题上，模型表现最差（ToM 问题的表现也好不了多少）。问答得分与智能体跨博弈的表现呈正相关。换言之，在这里知与行同步变化：模型表现差的地方，当直接向它们提出行动问题时，其推理也表现差。对于纯协调任务，缺陷在于采纳伙伴视角（ToM）和联合规划本身，而非将推理转化为行动。

在另一个层面上，知行差距再次出现。在 Hanabi 中，GPT-4-turbo 只有在配备了显式 ToM 推理和自我验证步骤时才能达到合理表现。没有这些支架，它在每次 Hanabi 试验中都会犯致命错误。换言之，它最初会做出错误行为，但在被提示检查推理和验证步骤时能识别并纠正这些错误。类似的表现在 MAgIC 中由概率图模型引起，在第 15 章讨论的策略行为研究中由社会思维链（Social Chain-of-Thought）引起。*LLM 无法推理他人*与*LLM 不会自发地运用此类推理*之间的界限显然很薄，而以结构化推理和验证步骤形式的智能体嵌入可以激发后者。

下一节考察对同一问题的不同但互补的应对方式：不是升级智能体的推理能力，而是通过分配角色来构建交互本身。

## 16.3 基于角色的任务解决与团队协作

在上一节中，智能体是对等的对称参与者，协调必须依靠它们自身的策略推理来实现（效果有限）。在本节讨论的研究中，协调是通过交互协议和分配具有不同目标的角色来预先设计的。

就第 16.1.3 节定义的五个维度而言，这些研究在保持整体交互类型为合作性的同时，变化了*策略*和*结构*。我们从最简单到最复杂的结构依次展开：互补对、多方辩论、团队以及压力下的社会角色扮演。

### 16.3.1 互补对

LLM 可以在成对设置中执行任务，被分配互补的角色，如创造者-批评者或管理者-执行者。在这些成对设置中，每个 LLM 智能体被赋予不同的角色和目标，它们通过交流共同完成任务。

在 CAMEL 框架（用于"心智"探索的通信智能体，Communicative Agents for "Mind" Exploration）[Li et al., 2023] 中，两个 LLM 拥有预定义的角色来执行任务，如完成编码目标（见图 16.4）。通过合作，它们共同驱动对话而无需持续的显式人类提示。CAMEL 使用起始提示（inception prompting）和角色描述来确保智能体保持角色并朝着目标协作。智能体被提示通过对话将复杂问题分解为可管理的步骤。在每个交互步骤中，LLM 智能体实际上在生成自己的推理时训练数据，使认知过程对人类可见以便检查，同时增强自主任务执行能力。

![图 16.4 CAMEL 中的角色扮演](/figures/figure_16_4.png)

其他研究将 LLM 创造者（或生成者）与 LLM 评判者（或批评者）配对，形成自我反思设置。通过这种方式，LLM 的生成能力由一个智能体发挥，而规则或质量准则的遵守由另一个智能体执行。Constitutional AI [Bai et al., 2022] 使用一个 LLM 根据一组伦理或质量准则来批评另一个 LLM 的回复，并提出修改建议。作者表明，这种双智能体反馈能产生与期望原则一致的精炼最终输出。

第三种成对交互形式遵循人类辅导动态：教师-学习者或专家-新手。第 19.2 节在蒸馏的背景下讨论了这种结构的多个例子。

所有三种配对方式都利用了同一个思想：一个智能体的监督可以纠正另一个的错误，从而产生比任一智能体单独实现更稳健的联合表现。

### 16.3.2 辩论与讨论

超越成对设置，基于角色的交互的一个突出示例是使用 LLM 之间的辩论和讨论来改善推理和任务表现。

Du 等人 [2024] 证明，当多个 LLM 实例提出答案并通过多轮辩论相互批评推理时，它们能以更高的事实正确性达成更准确的共识答案。这种方法以 Minsky 的"心智社会"（society of minds）[Minsky, 1988] 来描述，在数学应用题和事实问答等任务中显著减少了推理错误和幻觉。

Liang 等人 [2024] 提出了一种多智能体辩论（MAD）设置，其中两个 LLM 智能体在例如以牙还牙谈判中持对立立场（见第 15.4 节），而第三个智能体充当裁判。裁判的角色是引导讨论走向最终解决方案。结构化辩论鼓励发散性思维，可以使配备 MAD 的较弱模型（如 GPT-3.5）在具有挑战性的基准测试中超过没有 MAD 的较强模型（如 GPT-4）。作者讨论了他们的 MAD 设置如何克服模型支架中自我反思步骤的一个已知问题。自我反思可能引发所谓的*思维退化*（degeneration of thought）：一旦模型对某个解决方案方向产生信心，自我反思可能会强化这种信心，即使方向是错误的。在 MAD 辩论设置中，另一个智能体可以推动不同的方向以避免思维退化。

ChatEval 将这种辩论模式应用于文本评估 [Chan et al., 2023]。注意到当多个标注者协作时人类文本评估的质量会提高，作者创建了一个多智能体裁判团队，包含辩手智能体、多样化的角色规范和不同的通信策略（见图 16.5），超越了单智能体提示策略。

![图 16.5 ChatEval 中三种不同的通信策略](/figures/figure_16_5.png)

另一种同样受 Minsky 心智社会启发的方法是 ReConcile，一个被设计为不同 LLM 智能体圆桌会议的多智能体框架 [Chen et al., 2023b]。该框架通过多轮讨论增强 LLM 智能体之间的协作推理。智能体必须试图说服彼此以改进答案。在七个基准测试上的实验表明，置信度加权投票机制显著提升了 LLM 的推理能力。此外，作者发现多样性（使用不同的底层模型）对性能至关重要。

MindStorms 引入了基于 LLM 的实现 [Zhuge et al., 2023]，建立在 CAMEL 框架 [Li et al., 2023] 之上。报告了大量实验，最多使用 129 个智能体解决常见的 AI 问题：视觉问答、图像描述、文本到图像合成、3D 生成、自我中心检索、具身 AI 以及基于通用语言的任务解决。作者发现，在特定应用中，更多成员之间的头脑风暴优于较少成员之间的，更长时间的头脑风暴优于较短时间的。

### 16.3.3 基于角色的软件团队

基于角色协作的一个有趣应用是软件开发，由完全由 LLM 智能体组成的模拟团队来开发软件。

LLM 的自动化编程一直受到逻辑不一致和幻觉等问题困扰，这些问题会在整个开发流程中级联传播。MetaGPT [Hong et al., 2024] 建立在人类软件团队中被证明有效的工作流程之上。该框架将标准操作规程（SOP）转换为提示序列，并为智能体分配软件公司的角色：产品经理、架构师、工程师、QA 测试员。通过这种方式，智能体将结构化的中间产物沿着流水线传递。产品经理制作需求文档，架构师将其转化为设计，工程师编写代码。通过这种方式，复杂任务被分解为可管理的子任务，智能体可以逐步验证过程，显著减少错误。

类似地，Qian 等人 [2024] 引入了 ChatDev，一个虚拟软件公司，其中智能体通过开发过程的各个阶段进行协作：设计、编码和测试。协作被组织为*聊天链*（chat chain）：每个阶段被分解为指令智能体和助手智能体之间的简短对话（见图 16.6）。使用一种使智能体在回复前要求更多细节的通信协议，带来了作者所称的*去幻觉*（dehallucination），提高了每一步的可靠性。该框架展示了自然语言中的结构化通信如何促进多智能体协作。

![图 16.6 ChatDev 中的链式工作流](/figures/figure_16_6.png)

MetaGPT 和 ChatDev 硬编码了特定的组织结构，而 AutoGen [Wu et al., 2024] 提供了一个灵活的编程框架，基于可定制智能体之间的对话，可以组合 LLM、工具和人类输入。它被设计为一个开源平台，使开发者能够根据应用定义智能体和交互结构。实验证明了其在数学、编码、问答、娱乐等领域任务中的有效性。

### 16.3.4 社会角色扮演

上述系统分配角色以解决任务。最后一条研究路线分配角色是为了研究社会行为本身：当 LLM 智能体被置于社会要求高或充满冲突的情境中时，它们会怎么做？

在 SOTOPIA [Zhou et al., 2023] 中，智能体协调、合作和竞争以实现复杂的社会目标。SOTOPIA 环境通过从 90 个（自动生成的）社会场景中采样*交互片段*，结合 40 个具有各自个性、职业、秘密、背景故事以及与其他角色关系的角色（图 16.7），构建了一个庞大且多样化的任务空间。作者根据不同 LLM 的智能体与人类参与者的表现评估了社会智能，观察到以下趋势：

- 在涉及社会推理的静态基准测试中表现良好的模型（如 ToMBench，见第 15.5 节）不一定在交互式场景中成功，再次说明了知行差距（第 15.4 节）。
- 较弱的智能体会削弱其对话伙伴的表现，这与上述会话优势的效果相反——在那种情况下智能体相互防止思维退化等错误。
- 泄露秘密和违反社会规范的行为在所有模型中都有观察到，与第 15.6 节讨论的道德行为观察一致。
- 人类在最具挑战性的 SOTOPIA 任务上的表现显著优于表现最好的模型（GPT-4）。

![图 16.7 SOTOPIA 中具有冲突社会目标的场景说明](/figures/figure_16_7.png)

作者认为，SOTOPIA 的动态和交互性质对 LLM 智能体构成了静态基准测试系统性地无法揭示的独特挑战。

[Campedelli et al., 2024] 研究了极端环境下的社会交互。受臭名昭著的斯坦福监狱实验 [Zimbardo, 1972] 的启发，作者考察了在囚犯与监狱看守的环境中说服性和虐待性行为的出现。研究发现，分配的囚犯和看守人格对说服力和反社会行为的出现都有影响。至关重要的是，这表明反社会行为可以通过角色分配和特定的交互环境在 LLM 智能体中出现。这揭示了与原始人类参与者实验的惊人相似之处，并再次提醒我们模型的情境判断方式（通常反映人口平均道德规范）与智能体一旦被置于特定行动语境中时的行为方式之间的差距（另见第 15.6 节）。该研究还发现，角色分配并非中性的工程工具：它可以以不当方式塑造行为。

为了模拟合作环境中的策略决策，研究者引入了 GovSim [Piatti et al., 2024]。他们研究伦理考量、策略规划和谈判技能如何影响合作结果。大多数 LLM 无法达到均衡，因为它们无法理解自身行为对群体的长期影响。有趣的是，引入一种特殊的*普遍化*推理语言 [Levine et al., 2020]（提示模型提出康德式问题：*如果每个人都那样做会怎样？*）使更多模型能够实现可持续的结果。Bianchi 等人 [2024] 引入的 NegotiationArena 也展示了类似的结果。他们展示了 LLM 智能体如何在谈判场景中通过灵活对话进行复杂谈判。采用不同的行为策略，灵活对话显著改善了谈判结果。

### 16.3.5 小结

本节中的研究对第 15.4 节中识别的协调弱点做出了回应，其方式不是使单个智能体成为更好的推理者（如第 15.5.2 节那样），而是构建围绕它们的交互结构。互补角色告诉每个智能体其贡献应该是什么，而交互协议和 SOP 规定智能体何时以及以何种形式进行交流。在某些设置中，裁判或投票机制可以帮助将分歧引导至有成效的解决。

角色和交互协议在内部协调不足的情况下提供了关键的支架。这可以被视为第 15 章讨论的结构化推理方案（如社会思维链、概率图或围绕道德规则的审议）的多智能体类比。这些方案在不受约束的推理不足的情况下提升了表现。在单智能体和多智能体两种情况下，模型的潜在（社会、道德等）知识和行为是真实存在的，但需要通过显式结构来激活。

## 16.4 结语

本章从 LLM 智能体在策略博弈中的面对面交互出发，经过基于角色的协作模式及在实践中协调它们的多种设置，最终到达对多智能体系统何时有效或失败的关键评估。

在第 15 章中，我们发现了协调不良的单个模型，它们能形式化地预测伙伴的行为，却无法在智能体实现中依据该预测行动。这两种模式都迁移到了多智能体环境中。在基准测试和平台中（如 [Xu et al., 2024, Agashe et al., 2025]），交互的 LLM 智能体能够推理自身利益，却无法协调其行为以将这种推理转化为策略优势。一个核心问题是它们根据自身伙伴的视角来调节行为的能力，这一问题在心智理论的知行差距或字面-功能差距中已有预示（第 15.5 节讨论）。这与系统性地将智能体间错位（inter-agent misalignment）识别为多智能体系统主要失败类别的研究产生了共鸣 [Cemri et al., 2025]。

这一字面-功能问题再次联系到构念效度：正如通过心智理论测试并不能确立人类级别的社会推理能力，多智能体设置优于单个 LLM 查询也不能确立集体智能。强基线、匹配的推理预算，以及对协作结构和交互协议的消融分析，将是多智能体 equivalents 的第 15.5 节讨论的扰动 ToM 测试。多智能体领域需要更多研究来建立关于智能体型 LLM 交互现状的可靠实证图景。

最后，多智能体环境增加了新的风险类别。角色分配被证明能够在受斯坦福监狱实验启发的环境中激活反社会甚至虐待行为 [Campedelli et al., 2024]。在其他研究中，协调失误、级联幻觉和弱点的相互强化引发了规范违反、秘密泄露和任务表现下降。在有些情况下，指定角色和交互协议搭建了行为支架并提升了表现，而在其他情况下，它们成为了阻碍或风险来源。

在下一章中，我们将讨论角色和协议不是被分配而是从交互本身中涌现的研究。
