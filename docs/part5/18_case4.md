
# 案例4：用 LLM 智能体模拟社会

> **学习目标**
>
> 在本案例中，你将通过广泛采用的生成式智能体（Generative Agents）框架 [Park et al., 2023] 来了解基于智能体的社会模拟（agent-based social simulation）。具体而言，你将能够：
> - 运行和配置一个由 LLM 驱动的**多智能体社会模拟**（multi-agent social simulation）。
> - 参与一个结构化的**机器心理学**（machine-psychological）实验。
> - 比较两种**认知架构**（cognitive architectures）：标准记忆系统与带有负面偏差（negativity bias）的记忆系统。
> - 探究**人格描述**（personality descriptions）和架构选择如何塑造智能体的涌现行为（emergent behavior）。
> - 批判性地反思**提示脆弱性**（prompt fragility）、模型依赖性以及 LLM 驱动模拟的局限性。

## 18.1 社会模拟

在社会模拟中，生成式智能体（generative agents）是由 LLM 驱动的角色，它们与环境以及其他智能体进行交互。这些智能体可以规划活动、维护记忆，或反思自身经历。Park 等人 [2023] 提出的生成式智能体框架表明，由 LLM 驱动的角色能够共同产生可信的日常行为、社交互动，甚至是协调一致的群体活动——而这一切都源于一个相对简洁优雅的认知架构。

本案例的独特之处在于，你将为智能体使用**两种**不同的认知架构，在相同场景下分别运行，并比较其涌现行为。第一种架构对所有记忆一视同仁。第二种则引入了**负面偏差**（negativity bias）：负面经历会被更强烈地编码，也更有可能被提取和反思。我们将观察到，这种受认知心理学研究启发 [Baumeister et al., 2001] 的不对称性，会对实验中的智能体产生可测量的影响。

本章的目标是理解架构选择——在我们的案例中，是智能体内部处理的细微变化——如何导致涌现性的后果。你还将看到智能体人设（persona）有多么脆弱：人格描述中的一个词，或记忆权重的微妙调整，都可能从根本上改变智能体的行动、规划和反思方式。

## 18.2 背景知识

### 18.2.1 生成式智能体

Park 等人 [2023] 提出的生成式智能体框架表明，由 LLM 驱动的角色能够产生可信的日常行为、社交互动，甚至协调群体活动。每个智能体包含三个核心组件：

1. **记忆流**（memory stream）：一个带时间戳的日志，记录智能体所感知、执行和思考的一切内容。
2. **检索函数**（retrieval function）：当智能体需要行动时，它会根据记忆的时效性（recency）、重要性（importance）以及与当前情境的相关性（relevance）来提取相关记忆。
3. **反思机制**（reflection mechanism）：智能体定期从原始记忆中综合出更高层次的洞察。

智能体的**人格**（personality）由一段简短的自然语言描述定义——一个**暂存文件**（scratch file），其中规定了角色的姓名、年龄、习得和先天的特质以及生活方式。这段描述被包含在每一个 LLM 提示中，以此锚定智能体的行为。

### 18.2.2 坏比好更强大

当嵌入原始生成式智能体模拟中的 LLM 智能体受到批评时，它会形成一条记忆。一小时后受到表扬时，它会形成另一条记忆。只要两条记忆在时效性、相关性和重要性上相当，生成式智能体将以相同的优先级提取它们——一条负面，一条正面。

一般来说，用于基于智能体的社会模拟的认知架构会借鉴认知科学来产生可信的行为。时效性、相关性和重要性这些变量的设计，松散地受到人类记忆提取研究的启发。重要性变量捕捉的是类似于事件的唤醒度（arousal）或显著性（salience）的特征。然而，在原始模拟 [Park et al., 2022] 中，记忆系统实际上是**效价盲**（valence-blind）的：所有记忆——正面的、负面的、中性的——都以相同的权重进行编码和提取。

如果智能体是人类，它会对带有负面效价的事件区别对待：以更敏锐的感官细节进行编码，以更鲜明的生动性进行提取，并使其更有可能在后续思维中重新浮现。心理学研究发现，人们对侮辱的记忆比对赞美的记忆更持久。一次与同事的负面互动可以抵消数周的愉快交往。换言之，在我们的心理学中，**坏比好更强大**（bad is stronger than good）[Baumeister et al., 2001]，而这种不对称性在记忆领域的影响尤为深远。

在本案例中，我们测试了 NEVER（负面情感效价增强重述，Negative Emotional Valence Enhances Recapitulation）模型的实现效果，这是一种更接近人类的记忆提取机制。在经 NEVER 增强的智能体中，负面记忆在编码时获得更高的重要性分数。因此，它们更有可能被提取，也更有可能触发反思。该架构在其他所有方面保持不变。这使得我们可以进行一个受控的**机器心理学**实验，比较一种架构选择的 effects：效价盲记忆与效价敏感记忆。此外，你还将利用这一结构化设置来测试调整智能体初始化参数（包括人格描述和系统提示）的效果。

### 18.2.3 为何这对智能体设计很重要

本案例阐明了两个重要的启示：

1. **架构选择具有涌现性后果**：一个在组件层面看似无害的记忆加权参数，可能随时间推移在智能体的社交行为、情感基调和决策方面产生剧烈变化。这些涌现效应难以仅从架构本身预测。
2. **提示脆弱性**：智能体行为对人格描述和系统提示的内容高度敏感。微小的扰动可能产生大幅度的行为转变——这一现象在 LLM 文献中有时被称为**提示敏感性**（prompt sensitivity）。

## 18.3 实现

### 18.3.1 模拟环境

本模拟使用了 Park 等人 [2023] 的 Smallville 环境：一个以 2D 瓦片地图渲染的小镇，智能体在地点之间移动、与对象交互并进行对话。我们的模拟采用了一个简化场景：一间咖啡馆和三个智能体。请认识一下：

- **Dolores**：咖啡师。温暖、富有同理心、注重细节。**实验组**智能体——她将接受负面偏差处理。
- **Maeve**：另一位咖啡师，具有匹配的人格特征。**对照组**智能体——标准架构，无负面偏差。
- **Bernard**：咖啡馆经理。难以预测、情绪多变、偶尔带有对抗性。Bernard 充当一个自然的**压力源**（stressor）：两位咖啡师都会接触到这个社交摩擦的来源。

这一设置包含三个智能体，其中两个具有相似的角色和地位（在 Bernard 监督下工作的咖啡师），因此可以对智能体架构和初始化进行受控实验。在第一步中，Dolores 和 Maeve 被赋予相同的人格特质，并暴露于相同的环境中。唯一的区别在于 Dolores 处理记忆的方式：她使用 NEVER 实现，该实现以更高的重要性对负面记忆进行编码。

### 18.3.2 智能体架构

每个智能体维护以下内容：

- **人格描述**（personality description）（即暂存文件）：一段简短的文本，描述智能体的姓名、特质、职业、人际关系和目标。
- **记忆流**（memory stream）：一个带时间戳的观察、行动和反思列表。
- **当前计划**（current plan）：一段关于智能体打算做什么的简短描述。

### 18.3.3 认知循环

在每个模拟步骤（代表游戏内 10 秒的时间）中，每个智能体执行以下循环：

1. **感知**（Perceive）：观察环境的当前状态——其他智能体在做什么、正在进行的对话、周围环境的变化。
2. **提取**（Retrieve）：查询记忆流以获取相关的过往经历。
3. **规划**（Plan）：根据人格描述、提取的记忆和当前观察，使用 LLM 决定下一步行动。
4. **行动**（Act）：在环境中执行计划好的行动。
5. **反思**（Reflect）（周期性）：每隔数小时的游戏时间，从近期记忆中综合出更高层次的反思。

这些步骤中的每一步都涉及一次 LLM 调用。提示由智能体的人格描述（保持不变）以及相关的提取记忆和当前观察（动态变化）构建而成。

### 18.3.4 两种架构变体

你将使用检索函数的两种变体：

**变体 A：基线记忆检索**

检索基于时效性、相关性和重要性的加权组合。这是 Park 等人 [2023] 所描述的标准生成式智能体架构。

**变体 B：负面偏差记忆检索**

当新记忆被创建时，其情感效价（emotional valence）会被评估。检索函数增加了一个效价项。绝对效价被归一化到 $[0, 1]$ 区间，对于负面记忆乘以 1.5，从而产生检索优先级层次（负面 > 正面 > 中性）。检索分数变为：

$$score = \alpha_{rec} \cdot R + \alpha_{rel} \cdot L + \alpha_{imp} \cdot I + \alpha_{val} \cdot V \quad (18.1)$$

其中所有 $\alpha = 1$。因此：两种变体之间的唯一区别是增加了效价项；其他一切完全相同。

## 18.4 讨论

在完成实验后，请反思以下问题：

1. **提示 versus 架构**：你已经看到人格提示和记忆架构都会影响智能体行为。哪种手段更强大？哪种更可预测？如果要将模拟用于建模政策采纳等重要应用，你会选择哪种方式来塑造智能体行为，为什么？
2. **涌现行为**：你是否观察到任何令你惊讶的智能体行为——那些在人格或架构中并未明确指定的行为？在你看来，是什么机制产生了这些涌现行为？
3. **评估挑战**：你如何评估一个生成式智能体是否表现良好？效价分数是一个指标，但它本身也是 LLM 的判断。使用一个 LLM 来评估另一个 LLM（或同一个 LLM）的输出有哪些局限性？你能想到替代的评估方法吗？
4. **认知真实性**：负面偏差是认知心理学发现的一个实例。你能想到其他可以在架构层面实现的认知偏差或记忆效应吗？你预期它们的涌现效果会是什么？（例如考虑：确认偏差（confirmation bias）、可得性启发法（availability heuristic）、近因偏差（recency bias）。）

## 18.5 总结

在本章中，我们熟悉了生成式智能体模拟，并用它来探索智能体 AI 中两个重要现象：认知架构选择的涌现效应（负面偏差）以及智能体行为对提示内容的敏感性（提示脆弱性）。我们看到，记忆加权方式的微小变化——负面记忆获得更高的重要性分数——可以随时间推移对智能体行为产生可测量的转变。我们还看到智能体人设是脆弱的：人格描述的微小变化可能产生大幅度且有时不可预测的行为效应。

这些发现对于任何构建 LLM 驱动智能体系统的人都有实际意义。人设并不是行为的可靠锚点。架构——记忆的存储、提取和反思方式——以从代码中可能无法明显看出的方式塑造着行为。生成式智能体模拟领域尚处于年轻的发展阶段。本章的练习让你获得了核心机制和核心挑战的实践经验。随着该领域的成熟，提示鲁棒性、认知架构设计和涌现行为评估等问题仍将是核心议题。
